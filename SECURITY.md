# Security

Sahne runs in the browser and draws documents it is given: avatar documents (checked and trimmed by `normalize`), place documents and scripts. If you find a way for such a document to run script, break out of its sandbox or exhaust a page, please report it privately through [GitHub's private vulnerability reporting](https://github.com/mehrad77/sahne/security/advisories/new) rather than in a public issue.

Only the latest `main` is supported.
