# Packages

The packages of this repo's pnpm workspace: the Sahne stage engine and the packages around it. The repo's [README](../README.md) says what Sahne is and how to work on it.

| Package | What it is | Docs | Tests |
|---|---|---|---|
| [`sahne`](sahne/) | The paper-theatre stage engine: formats, director, rig, the WebGL2 and SVG backends, audio, interaction, the builder. Knows no language and no app | [README](sahne/README.md), [DESIGN](sahne/DESIGN.md) | `sahne/test/` |
| [`sahne-kit`](sahne-kit/) | The first kit: body, faces, hair, clothes, set pieces, props, sounds and music, all drawn in code | [STYLE](sahne-kit/STYLE.md), [CATALOGUE](sahne-kit/CATALOGUE.md) and [SET](sahne-kit/SET.md) (generated) | `sahne-kit/test/` |
| [`sahne-tr`](sahne-tr/) | The Turkish plugin: mouth timing, word ↔ token matching, say-it-aloud matching, numbers and clock times for the lints | [README](sahne-tr/README.md) | `sahne-tr/test/` |
| [`sahne-en`](sahne-en/) | The English plugin: the same for English (British spelling), and the words and lints of an English series (`sahne-story/src/langs/en.ts`) | [README](sahne-en/README.md) | `sahne-en/test/` |
| [`sahne-story`](sahne-story/) | The story format: the adapter, the player, the story check and lints, and `paths.ts`, where the story data lives (the content root: `$SAHNE_CONTENT`, or `sahne-story/samples/`) | [README](sahne-story/README.md) | `sahne-story/test/` |
| [`sahne-backstage`](sahne-backstage/) | The studio an app runs on its content root (`startBackstage`, its own port): a season board, episodes written as scripts beside a live stage, the kit as galleries, review, an assistant (Claude or a local model, within a budget), and an MCP server for agents; saved with the story check. Never ships to learners | [README](sahne-backstage/README.md) | `sahne-backstage/test/` |
| [`sahne-gallery`](sahne-gallery/) | The dev gallery (one page on :5180: systems, kit, places, stories), the size check and the `pnpm sahne` scripts | [README](sahne-gallery/README.md) | none of its own |

The set kit (set pieces and props) is its own entry, `sahne-kit/set`, in families an app loads when its places need them (`loadSet`, `withSet`); `sahne-kit/full` is the kit with all of them, for the gallery, the tests and the lints. `sahne-kit/set-svg` (`pieceSvg`) draws one piece or prop on its own as an SVG sketch, for a gallery tile or an editor's picker. `sahne-kit/SET.md` lists every set piece and prop (generated with `src/set/families.gen.ts` by `node packages/sahne-kit/set/build.ts`, `--check` in the tests). The kit's catalogue of people has two files: `sahne-kit/CATALOGUE.md` lists what is drawn and planned (generated by `node packages/sahne-kit/catalogue/build.ts`, never edited by hand); `sahne-kit/catalogue/plan.json` is the plan it reads. What a learner may pick is curated in `sahne-kit/src/curation.ts`.

## Checks

From the repo root:

```bash
pnpm check                          # the same as pnpm sahne check: types of all six packages, the size check, bundle determinism, the story and extras checks, the Node tests and the golden frames
node packages/sahne-gallery/size.mjs  # the size check alone (--json for an app's build)
```

`tsconfig.json` has `"types": []` and includes only each package's `src/`, so Node-only files (tests, `sahne-kit/sounds/build.ts`) are not type-checked by it; never `npx tsc`. `pnpm sahne check` runs 616 tests today: 608 pass on the samples, and 8 that need data the samples lack (a `needs.json`, Kumru's airport) are skipped. `size.mjs` bundles and minifies each package on its own, gzips it and fails over budget (`sahne/DESIGN.md` §12):

| Bundle | Budget (gzip) |
|---|---|
| Engine and Turkish plugin | 150 KB |
| Kit code | 150 KB |
| Each set family (`sahne-kit/set`) | 40 KB |
| Kerim's puppet (`sahne-kit/kerim`) | 8 KB |
| The animal puppets (`sahne-kit/puppets`) | 8 KB |
| Portraits (`normalize`, `portrait`, `silhouette`) | 20 KB |
| The builder with its stage | 100 KB (raised from 80 on 2026-10-13: it carries the whole stage) |
| The whole set, every family together | 250 KB, a warning only (365 KB today) |
| `sahne/listen`, `sahne-story` | measured, no budget |

CI (`.github/workflows/ci.yml`) runs `pnpm sahne check` on every push and pull request.

## Conventions

Every package here follows the same pattern (check `package.json` when adding one):

- `"private": true` and `"type": "module"`; not published to npm. An app takes the packages as a git submodule in its own pnpm workspace (Kumru has this repo at `sahne/`, with `sahne/packages/*` in its `pnpm-workspace.yaml`).
- `exports` points straight at TypeScript source (`"." : "./src/index.ts"`, and `sahne` adds `"./listen"`), with no build step. `sahne-backstage` also exports `"./server"`, its Node-only server (`server/`, outside `src/` and the type check).
- Erasable TypeScript only (`erasableSyntaxOnly` in [`tsconfig.json`](tsconfig.json), which type-checks all six), so Node 24 runs it directly and esbuild bundles it.
- Tests run with `node --test test/*.test.ts` (each library's `pnpm test`).
- Packages depend on each other, and apps on them, as `workspace:*`. `sahne` depends on nothing.

A new package's tests also join `pnpm sahne check` (the gallery's `check` script), which CI runs.

## Kerim

Kerim, the kumru (a collared dove) who narrates Kumru's stories, lives in the kit:
- her art, `packages/sahne-kit/src/kerim/art.ts` (exported as `sahne-kit/kerim/art`), which Kumru's page and `sahne-gallery/serve.mjs` import and Kumru's icon tool reads by regex for the brand files;
- her portrait for the narrator's round window, `packages/sahne-kit/src/kerim/portrait.ts` (exported as `sahne-kit/kerim/portrait`), which the gallery and sahne-backstage use;
- her CSS, `packages/sahne-kit/src/kerim/kerim.css` (exported as `sahne-kit/kerim.css`), which poses and animates her in an app; an app sets her drop shadow, `--k-shadow`, on `:root`;
- her stage puppet, `src/kerim/art.gen.ts`, converted from both by `node packages/sahne-kit/kerim/build.ts` (`--check` in the kit's tests).

Her art is not under the kit's art licence: see [LICENSE-ART](../LICENSE-ART).
